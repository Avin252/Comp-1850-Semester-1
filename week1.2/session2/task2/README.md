# Task 2

1. In the terminal, enter the command `python` to run a Python interpreter.

2. For each of the boolean expressions shown below, try to predict the
   value of the expression, then enter it into the interpreter to see if
   you were right.

   ```python
   not (3 > 1) # Prediction: False correct
   (4 > 2) and (6 > 8) # Prediction: False correct
   (5 == 5) or (2 > 10) # Prediction: True correct
   not (10 > 5 or 3 != 3) # Prediction: False correct
   5 < 10 < 15 # Prediction: True correct
   3 <= 3 < 10 and (10 == 10 or 5 > 8) # Prediction: True correct
   ```

3. Press `Ctrl+D` to exit the interpreter.
